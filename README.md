## ✨ Возможности

### 👤 Система авторизации
- 🔐 **Вход/выход** - простая система аутентификации
- 👥 **Личные события** - каждый пользователь имеет свои события
- 🕵️ **Режим инкогнито** - создание событий без авторизации

### 📅 Управление календарем
- 🗓️ **Просмотр года** - 12 мини-месяцев + увеличенный текущий месяц
- ➕ **Создание событий** - быстрое добавление с выбором времени и цвета
- ✏️ **Редактирование** - изменение названия, времени и цвета
- 🗑️ **Удаление** - с модальным подтверждением
- 🎨 **15 цветов** - для категоризации событий

### 🎯 Визуальные улучшения
- 🔔 **Toast уведомления** - визуальный feedback для всех действий
- ⏳ **Loader** - индикация процесса сохранения
- 🛡️ **Валидация** - с визуальной подсветкой ошибок
- 🌊 **Плавные анимации** - все переходы анимированы
- 📱 **Адаптивный дизайн** - работает на всех устройствах

### 💾 Хранение данных
- 📦 **Базовые события** - праздники в events.json
- 👤 **Личные события** - для каждого пользователя отдельно
- 🕵️ **События инкогнито** - сохраняются по годам
- 🔄 **Автосохранение** - все изменения сохраняются автоматически

## 🚀 Быстрый старт

### Требования

- PHP 7.0 или выше
- Веб-сервер (Apache, Nginx и т.д.)
- Современный браузер (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/kbgdov-dev/calendar.git
cd calendar
```

2. **Настройте права доступа:**
```bash
chmod 755 /path/to/calendar
chmod 644 /path/to/calendar/*.json
chmod 755 /path/to/calendar/users
```

3. **Настройте веб-сервер:**

**Apache:**
Убедитесь, что модуль `mod_rewrite` включен и PHP настроен.

**Nginx:**
```nginx
location ~ \.php$ {
    fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
    fastcgi_index index.php;
    include fastcgi_params;
}
```

4. **Откройте в браузере:**
```
http://localhost/calendar/
```

## 📖 Использование

### 👤 Авторизация

#### Вход в систему:
1. Введите логин и пароль
2. Нажмите "Войти"
3. Ваши личные события загрузятся автоматически

#### Демо-пользователи:
- **anna** / **password123**
- **konstantin** / **password456**

#### Режим инкогнито:
Работайте без авторизации - события будут сохраняться локально по годам.

### 📅 Создание события

1. Кликните на нужную дату
2. Нажмите "➕ Добавить событие"
3. Заполните:
   - Название события
   - Время или "Весь день"
   - Цвет события
4. Нажмите "💾 Сохранить"

### ✏️ Редактирование события

1. Кликните на событие в списке
2. Нажмите кнопку ✏️ редактирования
3. Измените нужные поля
4. Нажмите "💾 Сохранить"

**Примечание:** Дату изменить нельзя - удалите и создайте новое событие.

### 🗑️ Удаление события

1. Откройте редактирование события
2. Нажмите "🗑️ Удалить"
3. Подтвердите удаление

### Логика хранения

#### 1. Базовые события (events.json)
Праздники и повторяющиеся события в формате `MM-DD`:
```json
[
  {
    "date": "01-01",
    "title": "Новогодние каникулы",
    "time": "Весь день",
    "color": "#1E90FF"
  }
]
```

#### 2. Личные события (/users/{username}/events.json)
События авторизованных пользователей в формате `YYYY-MM-DD`:
```json
[
  {
    "date": "2025-05-15",
    "title": "День рождения",
    "time": "14:00",
    "color": "#E74C3C"
  }
]
```

#### 3. События инкогнито (events_${year}.json)
События неавторизованных пользователей:
```json
[
  {
    "date": "2025-12-31",
    "title": "Встреча",
    "time": "23:00",
    "color": "#3498DB"
  }
]
```

### Логика загрузки

При загрузке календаря:
1. **Базовые события** загружаются из `events.json` (всегда)
2. **События года** загружаются из `events_${year}.json` (если существует)
3. **Личные события** загружаются из `/users/{username}/events.json` (если авторизован)
4. Все события **объединяются** без дублирования

### Логика сохранения

При сохранении событий:
- **Авторизованные пользователи**: события сохраняются в `/users/{username}/events.json`
- **Неавторизованные (инкогнито)**: события сохраняются в `events_${year}.json`
- **Базовые события** (MM-DD) НЕ сохраняются в личные файлы

## 🔒 Безопасность

### Реализованные меры

1. **Сессии PHP** - безопасное хранение данных пользователя
2. **XSS защита** - экранирование HTML в `htmlspecialchars()`

4. **Резервное копирование** - автоматические бэкапы перед изменениями

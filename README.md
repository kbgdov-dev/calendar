# 📅 Интерактивный календарь

> Современное веб-приложение для управления событиями с красивым интерфейсом и плавными анимациями

[![Version](https://img.shields.io/badge/version-2.0.0-blue.svg)](https://github.com/kbgdov-dev/calendar)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![JavaScript](https://img.shields.io/badge/javascript-ES6+-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## ✨ Возможности

- 🗓️ **Просмотр года** - 12 мини-месяцев + увеличенный текущий месяц
- ➕ **Создание событий** - быстрое добавление с выбором времени и цвета
- ✏️ **Редактирование** - изменение названия, времени и цвета
- 🗑️ **Удаление** - с модальным подтверждением
- 🎨 **15 цветов** - для категоризации событий
- 🔔 **Toast уведомления** - визуальный feedback для всех действий
- ⏳ **Loader** - индикация процесса сохранения
- 🛡️ **Валидация** - с визуальной подсветкой ошибок
- 🌊 **Плавные анимации** - все переходы анимированы
- 📱 **Адаптивный дизайн** - работает на всех устройствах
- 💾 **Локальное хранение** - события в JSON файлах

## 🚀 Быстрый старт

### Онлайн демо
Откройте [GitHub Pages](https://kbgdov-dev.github.io/calendar/) для живой демонстрации.

### Локальный запуск

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/kbgdov-dev/calendar.git
cd calendar
```

2. **Откройте в браузере:**
Просто откройте файл `index.html` двойным кликом или через любой веб-сервер.

**Вот и всё!** Сервер не требуется, интернет не нужен.

## 📖 Использование

### Создание события
1. Кликните на нужную дату
2. Нажмите "Создать событие"
3. Заполните название, время, выберите цвет
4. Нажмите "Сохранить"

### Редактирование события
1. Кликните на событие
2. Нажмите кнопку редактирования
3. Измените данные
4. Сохраните изменения

### Удаление события
1. Откройте редактирование события
2. Нажмите "Удалить"
3. Подтвердите в модальном окне

## 🎨 Особенности дизайна

### Анимации
- **Модальное окно**: fade-in + scale эффект (0.2s)
- **Панель редактирования**: выезд справа + fade-in (0.2s)
- **Toast уведомления**: slide-in справа (0.3s)
- **Валидация**: shake анимация при ошибке (0.4s)

### Цветовая схема
Доступно 15 цветов для событий:
- 🔴 Красный - срочные/важные
- 🟢 Зелёный - личные дела
- 🔵 Синий - работа
- 🟣 Фиолетовый - хобби
- И другие...

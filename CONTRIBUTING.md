# 🤝 Участие в разработке

Спасибо за интерес к проекту! Мы рады любому вкладу.

## 📋 Как внести вклад

### 1. Сообщить о проблеме (Bug Report)

Нашли баг? Откройте [issue](https://github.com/kbgdov-dev/calendar/issues/new) с описанием:

- **Название**: Краткое описание проблемы
- **Описание**: Подробное описание что не работает
- **Шаги воспроизведения**: Как повторить проблему
- **Ожидаемое поведение**: Что должно происходить
- **Реальное поведение**: Что происходит на самом деле
- **Скриншоты**: Если применимо
- **Браузер и версия**: Где наблюдается проблема

### 2. Предложить улучшение (Feature Request)

Есть идея? Откройте [issue](https://github.com/kbgdov-dev/calendar/issues/new) с описанием:

- **Название**: Краткое описание идеи
- **Проблема**: Какую проблему решает
- **Решение**: Как вы представляете реализацию
- **Альтернативы**: Другие варианты решения

### 3. Внести код (Pull Request)

Хотите написать код? Отлично!

#### Процесс:

1. **Fork** репозитория
2. **Clone** на локальную машину:
   ```bash
   git clone https://github.com/your-username/calendar.git
   ```
3. **Создайте ветку** для вашей фичи:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Внесите изменения** и протестируйте
5. **Commit** с понятным сообщением:
   ```bash
   git commit -m "Add: повторяющиеся события"
   ```
6. **Push** в вашу ветку:
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Откройте Pull Request** в основной репозиторий

#### Требования к коду:

- ✅ Код должен быть читаемым
- ✅ Добавьте комментарии для сложной логики
- ✅ Следуйте существующему стилю кода
- ✅ Протестируйте в разных браузерах
- ✅ Обновите документацию если нужно

## 🧪 Тестирование

Перед отправкой PR протестируйте:

- ✅ Создание события
- ✅ Редактирование события
- ✅ Удаление события
- ✅ Валидация форм
- ✅ Анимации работают плавно
- ✅ Нет ошибок в консоли

### Браузеры для тестирования:
- Chrome (последняя версия)
- Firefox (последняя версия)
- Safari (если доступен)
- Edge (последняя версия)

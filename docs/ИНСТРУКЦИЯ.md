# 📅 Инструкция по использованию календаря

## 🚀 Быстрый старт

1. Распакуйте архив `calendar_COMPLETED.zip`
2. Откройте файл `index.html` в браузере
3. Готово! Календарь работает локально, сервер не требуется

---

## 📖 Основные функции

### 🗓️ Просмотр календаря

- Выбор года стрелками или вводом числа
- 12 мини-месяцев справа
- Большой месяц слева
- Даты с событиями подсвечены
- Информация о годе (високосный, китайский зодиак)

### ➕ Создание события

1. Кликните на дату
2. Нажмите "Создать событие"
3. Введите название
4. Выберите время или отметьте "Весь день"
5. Выберите цвет
6. Нажмите "💾 Сохранить"

✅ Появится toast "Событие успешно создано"

### ✏️ Редактирование события

1. Кликните на событие
2. Нажмите кнопку редактирования (✏️)
3. Измените название, время или цвет
4. Нажмите "💾 Сохранить"

✅ Появится toast "Событие успешно обновлено"

**ВАЖНО:** Дату изменить нельзя - она привязана к выбранному дню

### 🗑️ Удаление события

1. Откройте редактирование события
2. Нажмите "🗑️ Удалить"
3. Подтвердите удаление в модальном окне

✅ Появится toast "Событие успешно удалено"

## 🎨 Особенности

### 🔔 Уведомления (Toast)

- **Зелёные** - успешные операции
- **Красные** - ошибки
- Автоматически исчезают через 3 секунды
- Появляются в правом верхнем углу

### ⏳ Loader

- При сохранении кнопка меняется на "⏳ Сохранение..."
- Кнопка блокируется до завершения
- Короткая задержка для плавности UX

### ✨ Анимации

- Модальное окно плавно появляется с эффектом "pop"
- Панель редактирования выезжает справа
- Toast уведомления выезжают справа
- Все переходы быстрые и плавные (0.2-0.3s)

### 🛡️ Валидация

- Название события обязательно
- Время обязательно (или "Весь день")
- Невалидные поля подсвечиваются красным
- Анимация "shake" при ошибке
- Автоматический сброс подсветки через 2 секунды

## 💾 Хранение данных

Календарь использует JSON файлы для хранения:

- **events.json** - базовые события (повторяющиеся каждый год)
- **events_YYYY.json** - события конкретного года

### Формат события

```json
{
  "title": "Название",
  "date": "2025-01-15",
  "time": "14:00",
  "color": "#E74C3C"
}
```

Или для событий на весь день:

```json
{
  "title": "Название",
  "date": "2025-01-15",
  "time": "Весь день",
  "color": "#E74C3C"
}
```

## 🐛 Известные ограничения

### 1. Дату события нельзя изменить после создания

**Решение:** Удалите и создайте заново на нужной дате

### 2. События хранятся локально в JSON

**Решение:** Для сохранения между устройствами нужен бэкенд

### 3. Нет поиска по событиям

**Решение:** Будет добавлено в будущих версиях

### 4. Нет категорий/тегов для событий

**Решение:** Используйте цвета для группировки

## 💡 Советы по использованию

### 🎨 Используйте цвета

- **Красный** - срочные/важные дела
- **Зелёный** - личные дела

## 🆘 Частые вопросы

### Q: Как изменить дату события?

**A:** Дату нельзя изменить. Удалите событие и создайте новое на нужной дате.

### Q: Почему нет поля даты в форме?

**A:** Дата привязана к выбранному дню. Это логичнее и проще.

### Q: Можно ли создать повторяющееся событие?

**A:** Пока нет, но можно добавить событие в `events.json` вручную.

### Q: Как сохранить календарь?

**A:** События автоматически сохраняются в JSON файлы в папке.

### Q: Работает ли без интернета?

**A:** Да! Календарь полностью автономный.

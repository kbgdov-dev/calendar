# 📅 Инструкция по использованию календаря

## 🚀 Быстрый старт

### Установка

1. Распакуйте архив на веб-сервер с поддержкой PHP
2. Настройте права доступа:
```bash
chmod 755 /path/to/calendar
chmod 644 /path/to/calendar/*.json
chmod 755 /path/to/calendar/users
```
3. Откройте в браузере: `http://yourserver/calendar/`

---

## 👤 Система авторизации

### Вход в систему

1. Введите логин и пароль в форму входа
2. Нажмите кнопку "Войти"
3. При успешном входе появится приветствие

#### Демо-пользователи

| Логин | Пароль | Имя |
|-------|--------|-----|
| anna | password123 | Anna |
| konstantin | password456 | Konstantin |

### Работа без авторизации (инкогнито)

Вы можете работать с календарем **без входа** в систему:
- События будут сохраняться локально по годам
- Базовые события (праздники) будут доступны
- Каждый год хранится в отдельном файле `events_{year}.json`

### Личные события

После авторизации:
- ✅ Ваши события сохраняются отдельно в `/users/{username}/events.json`
- ✅ События других пользователей не видны
- ✅ Базовые события (праздники) видны всем
- ✅ Автоматическая загрузка при входе

### Выход из системы

1. Нажмите кнопку "Выйти" в правом верхнем углу
2. Ваши данные остаются в безопасности
3. При повторном входе события загрузятся автоматически

## 📖 Основные функции

### 🗓️ Просмотр календаря

- **Выбор года**: стрелками `<` `>` или вводом числа
- **12 мини-месяцев** справа - обзор года
- **Большой месяц** слева - детальный просмотр
- **Даты с событиями** подсвечены цветными полосками
- **Информация о годе**: високосный, китайский зодиак

#### Индикация событий

- **Полоски цветные** - первые 4 события
- **Точки** - дополнительные события (если больше 4)
- **Наведение мыши** - подсказка с названием

### ➕ Создание события

1. **Кликните** на нужную дату в календаре
2. **Нажмите** "➕ Добавить событие"
3. **Заполните форму:**
   - Название события (обязательно)
   - Время события или "Весь день"
   - Цвет события (15 вариантов)
4. **Нажмите** "💾 Сохранить"

✅ Появится уведомление "Событие успешно создано"

**Примечание:** Дата автоматически устанавливается по выбранному дню.

### ✏️ Редактирование события

1. **Кликните** на дату с событиями
2. **Кликните** на событие в списке
3. **Нажмите** кнопку редактирования ✏️
4. **Измените** нужные поля:
   - Название
   - Время или "Весь день"
   - Цвет
5. **Нажмите** "💾 Сохранить"

✅ Появится уведомление "Событие успешно обновлено"

**ВАЖНО:** Дату события изменить нельзя - удалите и создайте заново.

### 🗑️ Удаление события

1. **Откройте** редактирование события
2. **Нажмите** "🗑️ Удалить"
3. **Подтвердите** удаление в модальном окне

✅ Появится уведомление "Событие успешно удалено"

## 🎨 Особенности

### 🔔 Уведомления (Toast)

- **Зелёные ✅** - успешные операции
- **Красные ❌** - ошибки
- **Синие ℹ️** - информация
- Автоматически исчезают через 3 секунды

- При сохранении кнопка меняется на "⏳ Сохранение..."

- **Панель редактирования** - выезд справа
- **Toast уведомления** - slide-in анимация
- **Валидация** - shake анимация при ошибке
- Все переходы быстрые и плавные (0.2-0.3s)

### 🛡️ Валидация данных

- Название события **обязательно**
- Время **обязательно** (или отметка "Весь день")
- Невалидные поля подсвечиваются **красным**
- **Shake анимация** при попытке сохранить ошибочные данные
- Автоматический сброс подсветки через 2 секунды

## 💾 Хранение данных

### Архитектура файлов

```
calendar/
├── events.json              # Базовые события (праздники)
├── users/                   # Личные данные
│   ├── anna/
│   │   └── events.json      # События Anna
│   └── konstantin/
│       └── events.json      # События Konstantin
└── events_2025.json         # События инкогнито 2025
```

### Типы событий

#### 1. Базовые события
- **Где:** `events.json`
- **Формат даты:** `MM-DD` (например, `01-01`)
- **Видны:** всем пользователям
- **Примеры:** праздники, выходные дни

#### 2. Личные события
- **Где:** `/users/{username}/events.json`
- **Формат даты:** `YYYY-MM-DD` (например, `2025-05-15`)
- **Видны:** только авторизованному пользователю
- **Примеры:** дни рождения, встречи, задачи

#### 3. События инкогнито
- **Где:** `events_{year}.json`
- **Формат даты:** `YYYY-MM-DD`
- **Видны:** только в текущем браузере
- **Примеры:** временные напоминания

### Формат события

```json
{
  "title": "Название события",
  "date": "2025-05-15",
  "time": "14:00",
  "color": "#E74C3C"
}
```

Или для события на весь день:
```json
{
  "title": "День рождения",
  "date": "2025-05-20",
  "time": "Весь день",
  "color": "#F39C12"
}
```

## 🐛 Известные ограничения

### 1. Дату события нельзя изменить

**Причина:** Дата привязана к выбранному дню
**Решение:** Удалите событие и создайте заново на нужной дате

### 2. Нет поиска по событиям

**Статус:** Планируется в будущих версиях
**Обход:** Используйте просмотр года и цвета для фильтрации

### 3. Нет повторяющихся событий

**Статус:** Планируется в версии 4.0
**Обход:** Добавьте базовые события в `events.json` вручную

### 4. Пароли хранятся в открытом виде

**Статус:** Демо-версия, в продакшене используйте bcrypt
**Решение:** См. [PHP_BACKEND.md](PHP_BACKEND.md) раздел "Безопасность"

## 💡 Советы по использованию

### 🎨 Эффективная работа с цветами

- **Создайте систему** - используйте один цвет для одного типа событий
- **Красный** - срочные дела, дедлайны
- **Зелёный** - личные дела, отдых
- **Синий** - рабочие встречи
- **Оранжевый** - праздники, события
- **Фиолетовый** - хобби, развлечения

### ⏰ Управление временем

- **Используйте "Весь день"** для дней рождения и праздников
- **Указывайте точное время** для встреч и звонков
- **Создавайте события заранее** для лучшего планирования

### 📅 Организация календаря

1. **Еженедельный обзор** - просматривайте неделю вперед
2. **Ежемесячное планирование** - используйте вид года
3. **Годовой план** - добавляйте важные даты заранее
4. **Резервные копии** - файлы `.backup.json` создаются автоматически

### 👥 Работа в команде

- Каждый пользователь имеет свой календарь
- Базовые события (праздники) видны всем
- Личные события остаются приватными
- Используйте разные учетные записи для разных проектов

## 🆘 Частые вопросы

### Q: Как изменить дату события?

**A:** Дату изменить нельзя. Удалите событие и создайте новое на нужной дате.

### Q: Почему в форме нет поля даты?

**A:** Дата автоматически берется из выбранного дня. Это логичнее и быстрее.

### Q: Как создать повторяющееся событие?

**A:** Сейчас только вручную. Добавьте событие с датой `MM-DD` в `events.json`.

### Q: Где хранятся мои события?

**A:**
- Авторизованные: `/users/{username}/events.json`
- Инкогнито: `events_{year}.json`

### Q: Можно ли экспортировать события?

**A:** Пока нет, но планируется экспорт в .ics формат в версии 4.0.

### Q: Работает ли календарь офлайн?

**A:** Да! После первой загрузки интернет не требуется.

### Q: Как добавить нового пользователя?

**A:** Отредактируйте файл `users.json`:
```json
{
  "username": "newuser",
  "password": "password",
  "displayName": "New User"
}
```

### Q: Забыл пароль, что делать?

**A:** Посмотрите в файл `users.json` (демо-версия). В продакшене используйте восстановление пароля.

### Q: События дублируются после обновления

**A:** Обновитесь до версии 3.0.0, где эта проблема исправлена.
